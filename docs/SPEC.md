# 映序 · 首版规格

用户已确认 Windows 本地桌面工作台、深色剪辑风格、完整制作流程。项目本地保存，无云端部署。首版导入 TXT/Markdown 或粘贴正文；小说可分批分析，识别人物别名、主配角、外貌原文依据和待确认创作设定。用户可以编辑、生成或上传角色参考并确认定妆。

固定模式每段 15 或 30 秒；自动模式按内容选择 3–30 秒（也可以选择 15/30 秒）。新建项目默认根据台词、动作和节拍逐段推荐时长，也可选择固定时长；固定模式默认 30 秒，短片段适合快切。新片段使用 `segment-board`：模型按完整片段自行决定 3–12 个镜头和每镜时长，图片模型只调用一次，生成一张只包含编号镜头、镜头文字和画面的完整横版分镜板，不上传角色形象图片；服务端再从整板完整画布裁切出每个镜头的目标画幅图。模板只决定人工审核板的排版，不决定镜头数量，也不把多个独立图片拼成整板。生成视频时再按出场角色上传人物参考图，视频提示词最后固定追加“与参考素材完全一致”。旧作品保留 `legacy-shot`，继续使用九张独立图兼容历史数据。角色或镜头变更撤销受影响审核并使旧视频失效。审核通过方可提交视频。逐镜头由所选 MiniMax 或火山方舟模型生成，片段模式按模型和剧情推荐请求时长；MiniMax 输出在下载归一化时移除模型音轨，台词保留在分镜清单用于后续配音，视频画面严禁分镜板文字和字幕烧录。

只在用户在应用内显式点击生成，或授权 Agent 调用生成工具时请求真实模型。离线示例采用固定示例小说和文字分镜，不伪装 AI 分析或生图。未配置时明确提示。视频创建前持久化业务 ID，成功立即保存供应商 ID；响应不明时标记待核实且不重发 POST。已有任务恢复仅查询。失败镜头单独重试。导出检查当前模式所需的全部镜头可用且版本当前，不跳过缺失镜头；片段编号固定输出 001.mp4 等，导出保留审核板、分镜 CSV 与映射清单。

技术：Electron 隔离主进程，React/TypeScript/Vite 前端，Node loopback HTTP 服务，JSON 原子落盘，Sharp 图像校验/拼接，FFmpeg 视频校验/裁切/合并。密钥只保存在桌面 safeStorage 或环境变量，网页模式仅进程内保存；前端只能获取是否配置，不能回读密钥。输入验证、媒体根目录限制、同源写保护、外部下载 SSRF 防护。

Agent 通过 JSON CLI 或官方 SDK 的 stdio MCP 调用同一个 loopback 服务，默认复用有版本依据的素材，明确重做需单独指定。审核使用实际检查时的版本，由服务端原子校验。整板图片和全部竖屏裁切齐备后可独立导出编号审核板与映射清单供人审，无需先生成视频，也不改变审核状态；`approve_segment_board` 是提交片段视频前的整板审核门。详细契约见 AGENT-SPEC.md 和 AGENT.md。

验收：工作流与失效规则测试；提供商请求契约、失败/未知状态、任务恢复测试；真实浏览器导入/示例/编辑/审核/错误态与桌面/窄屏检查；构建及 Electron 启动；使用本地合成媒体验证视频拼接与数字导出。真实付费生成与文学/角色相似度验收单列。
