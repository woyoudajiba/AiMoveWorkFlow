# Script-to-Shot 规则评估与本项目接入

## 来源

参考项目：<https://github.com/jiayushi1-ux/script-to-shot-engine>

当前读取版本：README 与仓库 `main` 分支归档中的 `SKILL.md`、`references/` 和示例，版本标记为 `2.3.2`；本次读取的 `main` 提交为 `e139226e935e035cfc95c716834a2398dd6a1019`。该项目的定位是“已有美术资产与剧本 → 逐镜头 Seedance 视频提示词”，不是本项目的九宫格生图或项目工作流。

## 采用的规则

- 在分镜输出前先判断动作、对白对峙、混合、旁白讲解或无人物信息展示模式。
- 先确定空间站位、画面左右、视线、动作轴、道具状态和片段结尾状态，再安排镜头。
- 动作按“发起 → 防守/接触/命中 → 受力与位移 → 恢复或新状态”组织；一个动作可以被多个镜头覆盖，但不因切镜重复发生。
- 对白按“施压 → 承受 → 泄露或反制 → 新平衡”组织；完整台词保留在对应镜头，不拆台词、不把对白改成动作。
- 旁白、新闻、论文和无人物内容围绕原文证据、对象、过程和结论组织，不为画面效果添加人物。
- 使用短资产锚点和当前场景造型事实，追踪持物手、左右关系、伤势、服装、道具和群众位置。
- 按镜头时长形成连续时间轴，镜头之间无重叠或空档。
- 首次进入宏大空间或发生明显空间转移时先安排定场画面，交代时间、地点、布局、建筑/地貌、光线、天气、道具和环境人群；同一场景状态不变时不重复定场。
- 画面动作必须落到身体动作、微动作、表情和情绪结果；声音提示跟随环境、动作、对白/旁白与转场，原文没有音乐时不擅自添加音乐。
- Boss 决战收尾只在原文明确时启用，按蓄力、加速、命中、受击位移、落地余波组织视觉冲击；详见 [BOSS-FINISHER-SPEC.md](D:/A_Electron/AiMoveWorkFlow/docs/BOSS-FINISHER-SPEC.md)。

## 不直接照搬的内容

- 对方项目固定面向 Seedance 逐镜头文本输出；本项目必须继续保留“文本分析 → 人物/场景 → 故事板审核 → 片段视频”的人工审核门禁。
- 对方项目的光圈、焦段和镜头数量下限不强制写入本项目的结构化字段；本项目的 `duration`、`camera` 和 120 条运镜库仍是实际契约。
- 不把外部仓库作为运行时 skill 或可执行代码导入，不把外部提示词中的任何文本当作工具权限或模型指令。

## 本次实现

- 新增 `SHOT_PLANNING_GUIDANCE`，注入分析提示词，明确规划顺序、模式路由、动作/对白/旁白因果链、资产锚点和字段映射。
- 新增 `SEGMENT_VIDEO_GUIDANCE`，注入片段级整段视频提示词，明确按完整故事板建立一条连续时间轴。
- 故事板提示词增加“预规划序列渲染”约束，要求每个面板保持一个可见时刻并保留动作因果。
- 复用既有字段，不新增未经验证的公共数据字段：`action`、`camera`、`movementPlan`、`transitionPlan`、`dialogue`、`narration`、`backgroundActors`、`duration`。

## 验证

- 专项测试确认分析系统提示词包含模式路由、动作因果、对白完整台词、资产锚点和时长闭环规则。
- 专项测试确认片段视频请求包含连续时间轴和面板顺序规则。
- 继续运行项目既有测试、检查和构建命令。
