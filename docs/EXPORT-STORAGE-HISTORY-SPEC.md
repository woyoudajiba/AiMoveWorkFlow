# 导出存储与历史记录规格

## 目标

让同一份短剧导出结果同时具备可恢复的服务器原始文件和桌面端可直接使用的本地副本，并提供跨项目的历史记录页。

## 用户场景

- 桌面端完成“合成并导出”后，视频、设定板和清单自动写入应用根目录的 `output` 文件夹。
- 网页端不写入用户本机，只保留服务器媒体；用户从历史页下载或预览。
- 用户切换项目后仍能看到当前账号过去所有已完成导出。

## 功能要求

- Electron 默认输出根目录为运行应用所在目录下的 `output/`；开发模式为项目根目录下的 `output/`。`AI_FRAME_OUTPUT_DIR` 可覆盖该位置。
- 本地副本按账号哈希、项目和导出记录隔离：`output/<accountHash>/<projectId>/<exportId>/`。
- 每次导出复制 MP4、所有设定板 JPG、`manifest.json` 和 `分镜清单.csv`；复制失败时导出任务失败并保留服务器原始媒体，错误必须可见。
- 网页端不返回本地绝对路径或服务器物理路径；媒体继续通过现有受保护的 `/media/...` URL 提供。
- `GET /api/history` 只返回当前账号的已完成导出，按 `createdAt` 倒序，返回项目标题、片段信息、模板和受保护媒体 URL。
- 已完成导出写入独立的历史快照；后续修改人物、造型或分镜时只使当前导出失效，不从历史页删除已完成记录，服务器原始文件继续保留。
- 历史记录支持视频预览以及视频、设定板、CSV、manifest 下载；没有历史时显示空状态。

## 非目标

- 本轮不增加自动清理、云端对象存储迁移或跨账号共享。
- 本轮不改变已有导出编号、媒体 URL 或当前项目视频页行为。

## 安全与兼容

- 服务端复制目标必须限制在配置的 output 根目录内，拒绝符号链接和路径穿越。
- 所有历史查询和媒体访问继续使用当前登录会话及账号隔离。
- 旧项目没有导出记录时返回空列表；旧导出记录缺少可选字段时保持兼容。

## 验证

- 服务测试覆盖：本地副本、服务器原件、账号隔离、历史排序和历史媒体权限。
- `npm.cmd test`、`npm.cmd run check`、`npm.cmd run build`。
- 真实浏览器验证历史入口、空状态、预览、四类下载，以及桌面和移动布局。
