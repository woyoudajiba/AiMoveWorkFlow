# Agent 调用与真实图片验收规格

## 目标

使映序既能在工作台操作，也能由有本机权限的 Agent 通过 JSON CLI 和 MCP 调用同一套本地 HTTP API。以原创短篇《末班灯》完成一次真实 Qwen 分析、两个人物参考和首段九个分镜的 GPT Image 2.5 生图，保存可复核小说、项目、独立图片、九宫格和结果记录。

## 调用与边界

- Agent 客户端只连接显式指定的 `http://127.0.0.1:<port>` 本机服务，不向任意远程地址发送小说或素材。不接收模型 API 密钥，凭据继续由应用保管。
- CLI 输出结构化 JSON，MCP 使用标准 stdio 传输。提供状态、创建作品、读取作品、分析、人物/分镜编辑与生成、审核、任务查询/恢复、分镜预览导出和最终导出能力。文档给出可直接复制的启动及 MCP 配置。
- 付费操作不自动重发。Agent 重复调用默认复用已有同版素材/任务，明确重做必须单独指定；未知任务应查询/恢复，不能悄悄创建新任务。
- 视频生成与审核分开；Agent 不能把创建图片自动视为已获用户视频审核。审核工具必须显式声明已检查对应内容版本。
- 九宫格图片预览导出不依赖视频已生成，不隐式批准分镜；每格按数字编号，保留画幅与分镜文字映射。
- 不修改全局 Codex/MCP 配置，不自动付费生成视频，不部署。兼容现有 HTTP/桌面流程，UI 不作整体改版。

## 实施与验收顺序

1. 保存原创小说，启动独立本地应用数据目录，通过真实应用 API 分析与生成人物参考。
2. 并行实现 Agent CLI/MCP 和无需视频的九宫格预览导出，先测试本地边界及任务门禁。
3. 检查实际人物图后，用已确认参考生成一段九镜，逐张检查并导出预览；最终图片仍待用户审核后才能生成视频。
4. 使用 CLI 和真实 MCP 客户端执行发现/读取/受控写入验证；运行项目测试、语法和构建，记录付费调用的实际结果及失败，不将 mock 等同于生图效果。

## 限制

供应商状态成功不代表人物一致性或剧情正确，结果要单独目视检查；POST 响应不明时暂停该项且保留任务标识。允许继续其他不依赖失败结果的开发工作，不能盲目重试或更换模型。
