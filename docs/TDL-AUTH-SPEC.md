# 映序 TDL 账号登录

## 产品范围
- 使用已有 TDL / WorkHelper 账号密码登录、退出及恢复登录；本轮不新增注册、找回密码或云端改动。
- 登录入口固定为已验证的 `https://wsfile.cn/myladmin/api/auth`，沿用同一账号库；禁止明文 HTTP 和任意认证地址。
- 登录后显示用户名。登录前不能读取作品、模型配置或媒体，也不能提交 Agent 任务。
- 可选记住登录，仅保存 Windows safeStorage 加密的会话令牌，绝不保存密码。无加密能力时仅当前会话可用。

## 会话与安全
- 云端令牌仅驻留服务端；前端使用内存中的随机本机会话 ID，媒体通过 HttpOnly / SameSite=Strict cookie 验证，URL 同时携带非秘密的 accountKey，阻止旧页签跟随共享 Cookie 读取新账号媒体。
- 所有 API 必须通过本机 Host、Origin 和 X-Local-Client 校验。受保护 API 额外校验 X-Studio-Session，旧页签/Agent 不可跟随账号切换执行请求。
- `/api/auth/status` 返回公开用户及本机会话；`POST /api/auth/login` 接受 username/password/remember；`POST /api/auth/logout` 撤销本机并尽力撤销云端会话。
- 登录限速、请求体至多 8 KiB、固定错误文案。会话验证最多缓存 30 秒；过期/停用立即拒绝，离线验证失败拒绝业务操作，保留加密缓存供重验。
- Agent 首次调用绑定本次已登录会话；退出或换账号后需重新启动 Agent，不自动重试写请求、不接收云端密码或令牌。

## 账户数据
- 账户目录为 `accounts/<sha256(TDL user.id)>`；每账号独立作品、媒体和加密模型配置。新账号不继承进程全局模型密钥。
- 只有验证成功后才加载该账户工作区。已有授权任务保留在原账号工作区继续执行，不因退出转移归属；重启后仅登录账户恢复。
- 旧版根目录作品保留。提供用户主动导入入口，仅复制到当前账号，原文件保留；只允许一次归属，其他账号不暴露旧作品。导入不复制旧模型密钥，未完成旧任务标记待核实，不自动重新付费。
- 本机草稿及上次作品按账号独立存储；切换账户必须卸载旧工作台，旧草稿 flush 仍写回原账户。此隔离不替代操作系统磁盘权限。

## 实施与验收
1. 独立上游认证模块与模拟接口测试。
2. 本机会话、账户工作区、HTTP/媒体保护、Electron 加密存储。
3. 登录界面、过期提示、账户草稿、旧数据导入和 Agent 绑定。
4. 边界测试、真实浏览器模拟登录验收、构建与桌面 EXE 启动验证。

不使用真实账户密码测试，不创建云端账号，不提交付费图片/视频任务。真实账号登录由用户验收。
