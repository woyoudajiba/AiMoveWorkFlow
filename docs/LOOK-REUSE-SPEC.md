# 人物造型复用与分类

## 目标

同一项目、同一人物的身份参考图和历史造型图进入可复用资产库。用户从当前场景的角色名称打开资产库，按模型分类和造型名称选择已有图片后直接引用，不重新提交生图任务。

## 约束

- 资产按 `projectId + characterId` 隔离，沈砚的图片不能出现在其他人物的选择器中。
- 复用只复制项目内媒体 URL 和造型事实，不复制图片二进制，不产生新的图片供应商任务。
- 目标场景会写入新的引用版本并恢复为“待审核”，不能绕过现有的身份、造型和分镜审核门禁。
- 旧的造型版本继续保留；当前场景的服装可以在身份图、历史造型和新生成造型之间切换。
- 身份图和造型三视图使用纯白或近白背景，禁止场景、建筑、道具和环境背景；上游模型不满足时仍由人工审核拦截。

## 分类

新生成或上传的人物/造型图由当前项目文字模型返回 `category` 和稳定 `key`。模型失败时使用确定性回退分类，不能阻塞图片结果和复用。历史数据没有分类记录时按已有名称/服装文字建立 legacy 分类，并可继续复用。

## 接口

- `GET /api/projects/:id/look-assets?characterId=...`：读取当前人物的身份图、历史造型图和分类信息。
- `POST /api/projects/:id/looks/:lookId/reuse`：传入 `sourceAssetId` 和 `expectedVersion`，把选中的图片和造型事实复制到目标场景造型，目标版本待审核。
