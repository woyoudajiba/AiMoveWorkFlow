# Boss 战收尾视觉编排规格

## 目标

当原文明确出现 Boss 决战、首领/魔王、最后一击、必杀或战斗收尾时，只为整个作品按剧情顺序最后一个终局片段规划一次有因果的高冲击收尾，让观众看清蓄力、命中、受击结果和最终状态。普通 Boss 战和阶段性击败不使用这套高强度效果，避免视觉疲劳。

## 非目标

- 不把普通动作、对白或旁白片段强制改成满屏特效。
- 不在同一作品的多个片段重复启用 Boss 收尾；每个作品最多一次。
- 不凭空增加超能力、武器、服装、角色或场景破坏。
- 不把每个镜头写成独立视频，也不改变故事板一段一个视频的契约。
- 不要求视频模型逐字执行所有特效词；真实画面仍以已审核故事板和角色/场景参考为准。

## 规划要求

1. 先确认空间和角色关系，再安排蓄力或起势。
2. 使用“蓄力/准备 → 闪现或加速 → 命中瞬间 → 受击位移 → 落地/余波/新状态”作为主因果链。
3. 命中瞬间可以短暂慢动作、冻结帧或极短冲击特写，但必须回到连续动作，不能让整段停成静态海报。
4. 粒子、光尘、碎裂光、能量爆发、运动模糊、动态阴影和镜头震动都必须绑定具体动作方向和结果，不能随机堆叠。
5. 服装、妆容、发型、武器持有手、角色脸部和场景空间保持已审核事实；受伤和破坏只有原文明确时才加入。
6. 对血雾、伤口等内容采用模型可接受的非写实化冲击表现，不能凭空增加血腥细节；原文没有伤害结果时使用尘土、碎光、衣摆和能量冲击表现力量。

## 推荐运镜

从 120 条运镜库中按动作需要选择少量方案，例如定场 `move-45`、粒子凝固 `move-50`、极速推入定格 `move-52`、低机位慢动作 `move-55`、子弹时间 `move-56`、慢动作环绕 `move-95`、冲击震动 `move-27`。不要在同一镜头叠加多个主要运镜。

## 验证

- 普通片段不包含 Boss 收尾专用提示词。
- Boss 收尾片段的故事板和整段视频提示词包含完整因果链、角色一致性约束、特效方向和最终状态。
- 现有分析、故事板审核、视频人工审核和导出门禁保持不变。
