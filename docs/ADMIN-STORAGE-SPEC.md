# Spec: 云端管理员数据台账与清理

## 目标

在 `/workf/admin/` 提供独立管理员入口，查看所有 TDL 账号的项目占用情况，并能删除单个项目或清理云端生成媒体与分析缓存。

## 非目标

- 不把管理员身份混入普通 TDL 账号体系。
- 不把管理员密码、原始密码、API key 或供应商回执返回给浏览器。
- 不默认删除账号身份文件。

## 用户场景

管理员登录后按账号和项目查看标题、更新时间、图片/视频数量与大小、分析数据大小；删除前看到明确影响范围。全局清理保留项目基本索引与原始内容，清除可再生成的分析结果、媒体和供应商回执；单项目删除移除该账号下的项目 JSON、媒体、回执和分析检查点。

## 功能要求

- 管理员密码只接受服务器环境中的 `AI_FRAME_ADMIN_PASSWORD_HASH`，使用 scrypt 哈希校验。
- 管理员会话使用独立 HttpOnly、SameSite=Strict、生产环境 Secure Cookie；普通 TDL Cookie 不能调用管理员 API。
- 管理员 API 提供登录、状态、退出、项目列表、摘要、单项目删除和全局清理。
- 所有账号目录、项目 ID 和删除路径服务端重新校验并拒绝符号链接、路径穿越和未知文件类型。
- 单项目删除允许管理员强制处理活动任务；工作区会阻止晚到任务重新写回项目文件。
- 全局清理会停用已加载工作区、清空媒体和供应商回执、重置项目派生分析数组，再重新加载工作区；账号身份与项目基本索引保留。
- 页面提供登录、搜索、刷新、退出、单项目删除、全局清理确认和操作结果状态。

## 验证计划

- Node 测试覆盖密码哈希、管理员会话隔离、未授权 401、项目列表、路径穿越、单项目删除与全局清理边界。
- 运行 `npm.cmd test`、`npm.cmd run check`、`npm.cmd run build`。
- 用真实浏览器打开 `/workf/admin/`，验证登录、列表、删除确认和响应式布局；再验证普通用户 API 仍受原有会话保护。
- 部署后检查服务状态、管理员页面、管理员登录和云端媒体/回执/分析目录计数。

## 风险和开放问题

- 已授权的全局清理不可逆；部署前保留一次受限备份并在清理后删除备份，避免继续留存敏感媒体。
- 供应商后台的远程任务不受本地删除影响，管理员页面只清理本地云端副本与回执。
